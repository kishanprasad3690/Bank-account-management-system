# Development Plan & Timeline

## 3. Module Breakdown (Based on Blueprint Responsibilities)
To ensure all project requirements are met, the development was divided into these 5 core responsibility modules:

* **Module 1 - OOP (`BankAccount`):** 
  * Implementation of core classes and objects.
  * Development of basic account functions.
* **Module 2 - Account Management:** 
  * Implementation of Create, search, update, and delete accounts functionalities.
* **Module 3 - Banking Operations:** 
  * Development of Deposit, withdraw, balance checking, and transaction history logic.
* **Module 4 - File Handling & Reports:** 
  * Implementation of Save/load data to files (`accounts.txt`, `transactions.txt`). 
  * Generation of system reports and the low balance alert feature.
* **Module 5 - Git / Testing / Integration:** 
  * Management of Version control (Git workflow and branching).
  * Performing unit and integration testing.

## 4. Git & Version Control Workflow
The following Git workflow was utilized to ensure continuous integration and documentation:
1. `git init` - Initialize repository
2. `git add .` - Add changes
3. `git commit -m "message"` - Commit changes with descriptive messages
4. `git push` - Push to remote repository
5. **Branches Used:**
   * `git branch` - Create branch for separate features
   * `git checkout` - Switch branch
   * `git merge` - Merge branch back into the main timeline
